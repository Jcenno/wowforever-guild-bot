3. DEPLOY ROUTINE (Worker) — no wrangler available
================================================================
1. Edit worker/src/*.js. node --check src/index.js ; node scripts/build.mjs ; npm test
2. Cloudflare dashboard -> Workers & Pages -> guild-bot -> Edit code
   https://dash.cloudflare.com/0f633783ba2e7b9940b58bb5d9e079a5/workers/services/edit/guild-bot/production
3. Click in editor, Ctrl+A, Delete, then type the whole dist/worker.paste.js (Chrome "type" action works; ~47 KB).
4. Ctrl+End: the editor auto-inserts a stray "}" on the last line. Delete it (two Backspaces) BEFORE Deploy. The 4 TypeScript warnings in Problems are noise.
5. Deploy. Then load https://guild-bot.jcenno.workers.dev/register once (new/changed commands). 429 = rate limited, wait 30 s.
6. Settings changes (variables/secrets) go through Settings -> Variables -> Deploy. NEVER deploy from the code editor right after a Settings change: the editor deploys the settings it loaded with and wipes newer ones (this happened once). Reload the editor first, or re-check Settings after.
7. Schema changes: D1 console, run ALTER/CREATE by hand:
   https://dash.cloudflare.com/0f633783ba2e7b9940b58bb5d9e079a5/workers/d1/databases/7131222f-3338-4b77-96ec-c832a730f7ce/console
8. Logs: Worker -> Observability. Find/replace inside the editor is unreliable; always full paste.

6. LESSONS / GOTCHAS
================================================================
- Discord Section (type 9) needs an accessory; use a plain Text Display (type 10) when there is no icon (enchants have none).
- Interactions must answer in 3 s: /iam defers (type 5) then PATCHes @original; Close early edits first, the handoff reply posts after via waitUntil. Need/Greed presses answer ephemerally and PATCH the card via waitUntil (so the presser sees feedback).
- D1 binds max 100 params; slice crafters to 6 before the IN query.
- news.py dedupe key keeps dates (month names normalised, tokens sorted); legacy_key() keeps old state entries valid. Changing the key shape without that re-posts the backlog (happened once; fixed within one run).
- GitHub's cron is unreliable; keep the Worker heartbeat.
- Blizzard profile lookups are strict on spelling; names with spaces are hyphenated slugs (us:whizz-aard).
- Chrome: Discord message "More" menu -> Delete/Pin; kicking members is blocked for the assistant.
